此刻的心情 · 使用文档

大模型在回复里内嵌 :名称: 标签，插件在发送链路把它替换成对应图片。围绕 meme_def（一张图的唯一名字）与 tags（多图共享的分组）两个概念工作。

核心概念

meme_def 指向唯一一张图，模型输出 :真冬_低头: 精确发送；tags 指向一组图，输出 :二次元: 或 :二次元:疲惫: 时按评分挑一张最合适的。

工具 API（模型调用）

工具mood_check_memes_def

按 meme_def 精确查询一张图的描述、tags 和发送 marker。

参数类型必填说明
meme_defstring必填唯一表情定义，如 真冬_低头
工具mood_rough_search_memes

用自然语言在 meme_def、描述、tags、来源中模糊搜索候选。

参数类型必填说明
querystring必填想表达的动作、情绪、角色或场景
limitinteger可选最多返回数量，1–20，默认 8
工具mood_steal_memes

导入一张图片入库。

参数类型必填说明
image_pathstring必填本地路径或 http/https 地址
meme_defstring必填唯一定义，建议 角色_动作
tagsarray必填至少一个分组 tag
descriptionstring必填画面、情绪和适用场景

用户命令

命令mood_check [数量]

展示当前会话最近触发的表情包记录（含 asset_id、meme_def、tags、使用次数）。

命令mood_delete <asset_id>

按 asset_id 删除一张图（需管理员）。先用 mood_check 查 ID 再删除。

发送与解析

  1. 标签命中 meme_def → 精确发送唯一图片。
  2. 未命中 → 解释为 tag，单/组合 tag 走降级评分。
  3. 同分按 meme_def 字典序稳定决胜（不随机）。
  4. 完全未命中 → 静默删除标签。

旧库格式化

点顶部「格式化旧库」。用视觉模型重新识别旧库或其他插件目录的图片并迁移，支持断点续传与部分提交。确认提交后，识图失败项将被永久删除（确认页会提示）。
